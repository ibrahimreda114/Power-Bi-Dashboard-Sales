Power BI Sales Dashboard Project
🛠️ Tools Used

Power BI | Excel | Power Query | DAX

📋 Project Overview

This project focuses on analyzing and visualizing sales performance data using Microsoft Power BI.
It demonstrates how to transform raw data into meaningful business insights through data cleaning, data modeling, and interactive visualizations.

🔧 Steps Followed
1️⃣ Data Preparation

Imported raw sales data from Excel files.

Cleaned and transformed data using Power Query to ensure consistency and accuracy.

2️⃣ Data Modeling

Created structured data models with proper relationships between tables.

Ensured referential integrity for accurate reporting.

3️⃣ Analysis & DAX Measures

Built custom DAX measures, including Time Intelligence functions, to track key performance indicators (KPIs) like Sales, Revenue, and Target Achievement.

4️⃣ Visualization

Designed interactive dashboards showing:

Sales by Region, Category, Channel, Product, and Sales Rep ID

Revenue vs. Target comparisons

Monthly Sales trends and regional contributions

5️⃣ Interactivity

Added filters and slicers (Region, Category, Date, Product, Channel, Sales Rep ID) for deeper exploration.

✨ Highlight Feature

Developed a single dynamic dashboard where users can toggle between Volume and Revenue views using a slicer — making analysis more efficient and insightful.
